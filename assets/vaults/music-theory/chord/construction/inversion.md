# Inversion

An **inversion** is the same chord — same notes, same name — with a different chord tone in the bass. Root position has the [[root]] on the bottom; first inversion puts the third on the bottom; second inversion puts the fifth on the bottom. Nothing about the chord's identity changes — only which note you hear underneath it.

Run [[chord_inversions]] with `tonic="C4"`, `quality="major"`, and cycle `inversion` through 0, 1, 2 — same three notes (C, E, G) every time, reordered. This is the root-vs-bass distinction in action: the root is always C, but the bass note — the lowest note sounding — changes with the inversion.

Inversion is one axis of [[voicing]]: it controls what's in the bass, while voicing more broadly covers register, doubling, and spacing of everything above it.
