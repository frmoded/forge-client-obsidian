# Chord Function

This section is about how chords behave together over time — the roles they play inside a key, the sequences they form, and how those sequences punctuate.

- [[diatonic_chord]] — the seven chords built on each degree of a scale, the default vocabulary of a key.
- [[harmonic_function]] — the job a chord plays: tonic, dominant, or predominant.
- [[chord_progression]] — an ordered sequence of chords over time.
- [[cadence]] — how a progression punctuates: authentic, plagal, half, deceptive.

Build your own progression in [[chord_progression]] and listen for the difference a cadence makes.
