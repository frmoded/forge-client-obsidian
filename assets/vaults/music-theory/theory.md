# Music Theory

This is the music theory section of the music-theory vault — the vault's prose-and-practice side. Where the rest of the vault (see [[README]]) is a library of composable action notes for building music21 scores, the concept notes here (`note/`, `scales/`, `chord/`, with exercises in `theory_exercises/`) are where the underlying ideas live: what a note, a scale, a chord actually are, explained so you can build them yourself, not just read about them.

Every theory note here follows the same shape: a short concept explanation, then a click-through to an action note that lets you hear or construct that concept directly. A note that doesn't make you press Run at least once has skipped the point.

Current sections:

- [[note]] — the atom of music: how a note is named (notation) and what it physically is (physics).
- [[scales]] — scales as ordered pitch sequences built from interval patterns; hear one, then build one yourself.
- [[chord]] — chords built by stacking thirds: triads, seventh chords, inversions, voicings, chord symbols and Roman numerals, and how chords function together in progressions and cadences.

Start wherever your question starts. Everything cross-links back to this page.
