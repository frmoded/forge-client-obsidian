# Chord Symbol

A **chord symbol** is the pitch-specific name a performer reads off a lead sheet: C, Dm7, G7, Bdim. It names an exact chord — root, quality, and any extensions — with no reference to what key you're in. "G7" is G7 whether the song is in C major, G major, or nowhere near a key at all.

Run [[experiments/build_seventh_chord]] with `tonic="G4"`, `quality="dom7"` to hear exactly what the symbol "G7" refers to. Chord symbols are absolute — contrast that with [[roman_numeral]], which names the *same* chord relative to a key instead of by its literal pitches.

A chord symbol can also carry an explicit bass — see [[slash_chord]] for what the `/` means.
