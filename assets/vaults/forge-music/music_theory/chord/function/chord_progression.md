# Chord Progression

A **chord progression** is an ordered sequence of chords over time — ii–V–I, the 12-bar blues, I–V–vi–IV. This is the horizontal dimension of harmony: not what a chord IS, but what happens as one chord moves to the next. Whole genres are recognizable by their go-to progressions.

Build one yourself in [[experiments/chord_progression]] — set `key_name`, `mode_name`, and a `progression` list of Roman numerals, then press Run to hear it realized as real chords in real time. Try the classic pop turnaround `["I", "V", "vi", "IV"]`, then try reordering it — same four chords, different progression, different feel.

Every progression is built from [[diatonic_chord|diatonic chords]] moving between [[harmonic_function|functions]], and every progression ends somewhere — see [[cadence]] for how that ending punctuates.
